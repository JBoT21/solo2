My second solo flutter project,

## Getting Started

This project demonstrates a small flutter project that shows how to:
1. Collect, Process, and Validate user input
2. Utilize state management
   
To use this app, you must have:
-Android Studio
-Flutter SDK
-An Android device emulator set up.

In this simple tip calculator app, all you have to do is put in the price paid for the meal, 
choose the quality of service, and the app will return your total price, with the tip calculated.
Additionally, when clicking on empty space, the app will change between 1 of 5 colors.

(Edge case: If the user attempts to put anything that isn't numbers, it will reject that input.
